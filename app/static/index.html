API

Každé měřidlo má vlastní API a vlastní token. Čtení je veřejné, zápis chrání token daného měřidla.

Měřidla a tokeny

Měřidla určuje meters.json ve stejném volume jako databáze, v kontejneru /data/meters.json. Token nahraďte dlouhým náhodným řetězcem. Volitelný color je hex odstín pro akcent karty a detailu. 

{
  "meters": [
    {"slug": "sklad", "name": "Sklad", "color": "#4f9d69", "token": "dlouhy-nahodny-token"}
  ]
}

Zápis hodnoty

POST /api/meters/{slug}/readings s hlavičkou X-API-Token (nebo Authorization: Bearer). Volitelný comment může mít až 500 znaků. 

curl -X POST http://localhost:8080/api/meters/$SLUG/readings \
  -H "Content-Type: application/json" \
  -H "X-API-Token: $METER_TOKEN" \
  -d '{"value": 0.42, "comment": "ranní kontrola"}'

Čtení

GET /api/meters vrátí seznam měřidel bez tokenů. GET /api/meters/{slug}/readings?hours=24 data pro graf a GET /api/meters/{slug}/readings/all všechna uložená měření včetně komentářů. 

curl http://localhost:8080/api/meters
curl http://localhost:8080/api/meters/$SLUG/readings/all

Komentáře jsou součástí veřejných dat.
