API

Čtení je veřejné, zápis chrání token. Hodnota 0.00 je nejlepší, 1.00 nejhorší.

Zápis hodnoty

POST /api/readings s hlavičkou X-API-Token (nebo Authorization: Bearer). Volitelný comment může mít až 500 znaků. 

curl -X POST http://localhost:8080/api/readings \
  -H "Content-Type: application/json" \
  -H "X-API-Token: $API_TOKEN" \
  -d '{"value": 0.42, "comment": "ranní kontrola"}'

Všechny hodnoty

GET /api/readings/all je veřejné, bez tokenu. Vrací všechna uložená měření vzestupně, včetně komentářů. 

curl http://localhost:8080/api/readings/all

Odpověď má tvar {"count": N, "readings": [...]}. Komentáře jsou součástí veřejných dat.
